# GoNax Model Specification: Scots Pine Empirical Multi-Feature Regressor (BAAD v1.0.1)
Model Identifier: trained-pinus-sylvestris-baad-v1
Species: Pinus sylvestris (Scots Pine, Family: Pinaceae)
Category: Scientific Trained Machine Learning Model
Framework: Scikit-Learn Ridge Regressor (L2 regularized)
Training Date: 2026-10-02
Status: Active Production Model

## 1. Model Overview and Mathematical Specification
The Scots Pine Empirical Multi-Feature Regressor is a scientifically trained machine learning model designed to estimate total aboveground dry biomass (AGB, in kg) for Pinus sylvestris.
The model employs an L2-regularized linear ridge regression with compound structural features:
Features:
1. dbh_cm (Stem diameter at breast height, 1.30 m)
2. height_m (Total tree height in meters)
3. cylindrical_volume_proxy_m3 = (pi / 4) * ((dbh_cm / 100) ^ 2) * height_m

Model Equation:
AGB (kg) = (1.857214 * dbh_cm) + (0.008603 * height_m) + (155.459116 * cylindrical_volume_proxy_m3) - 14.482796

## 2. Carbon and CO2 Equivalent Conversion Parameters
Once aboveground dry biomass is estimated:
1. Carbon Fraction: 0.505 (50.5% elemental carbon), calibrated according to Thomas & Martin (2012) for boreal and temperate Pinus species.
   Carbon (kg) = AGB (kg) * 0.505
2. CO2 Equivalent Factor: Stoichiometric ratio 44.01 / 12.011 ≈ 3.6667 (IPCC 2019).
   CO2e (kg) = Carbon (kg) * 3.6667

## 3. Calibration Domain and Envelope Limits
The model is trained strictly within the physical empirical boundaries of the BAAD Scots pine harvest cohort:
- Diameter at Breast Height: 1.10 cm to 41.95 cm
- Total Tree Height: 2.10 m to 32.40 m
- Biomass Calibration Span: 0.291 kg to 1,106.58 kg
Operational Rules:
- If tree measurements fall within these boundaries: Confidence tier is HIGH_CONFIDENCE.
- If DBH or height exceeds these limits: GoNax emits an EXTRAPOLATION_WARNING, widens confidence intervals, and flags potential non-linear stem taper breakdown.

## 4. Empirical Evaluation Metrics
Evaluated on a held-out test split (44 destructive harvests) using 5-fold cross-validation:
- Test R² (Coefficient of Determination): 0.9675
- Test Root Mean Squared Error (RMSE): 31.78 kg
- Test Mean Absolute Error (MAE): 11.59 kg
- Residual Standard Error (RSE): ±38.76% (driven primarily by young saplings with high proportional needle mass).
Comparative benchmark against alternatives:
- Standard Power Law (Zianis allometry): Test R² = 0.8844, RMSE = 59.92 kg
- Random Forest Regressor: Test R² = 0.9219, RMSE = 49.28 kg
- Gradient Boosted Trees: Test R² = 0.9532, RMSE = 38.12 kg
The multi-feature Ridge Regressor was selected because it preserves physical monotonicity and avoids tree-based step discontinuities while achieving superior out-of-sample generalization.

## 5. Geographic Applicability
Calibrated on boreal and montane European stands:
- Sweden (Central Boreal, Albrektson 1984)
- Finland (Southern Boreal, Vanninen & Mäkelä 2005)
- Spain (Sierra de la Demanda montane pine, Santa Regina 1999)
Latitude range: 40.3°N to 61.8°N; Longitude range: -4.5°W to 24.2°E.
Applying this model to Mediterranean dryland pines or North American pine plantations requires geographic validation.
